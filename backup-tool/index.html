Backup tool

This is a private backup utility operated by Kobci. It copies encrypted backups of Kobci's own working files to Kobci's own Google Drive storage. It uses the open-source program rclone under a Google sign-in registered by Kobci.

The tool is used only by its operator. It is not offered to the public, to Kobci customers or to any other person, and nobody else can sign in to it.
